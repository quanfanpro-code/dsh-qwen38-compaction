# 压缩失败停止聊天实施计划

目标：失败后无普通聊天请求，成功后可恢复。

技术：已有 Node.js、DSH 原生循环和事件记录；串行执行，不新增依赖。

设计：docs/superpowers/specs/2026-09-10-failure-stop-design.md。

1. tests/失败阻止聊天.test.mjs：使用现有 HTTP 合成服务与原生循环，覆盖自动失败、手动失败及取消、会话恢复、成功解锁。先运行 `node --test tests/失败阻止聊天.test.mjs`，应因普通聊天被放行失败。
2. scripts/构建.mjs 与 src/失败拦截.mjs：删除自动压缩的放行分支；在下一步入口读取最近一次压缩结果。构建后重新运行上述测试，预期两项通过。
3. 运行 `node --test tests/*.test.mjs`；更新说明和版本 0.1.3，打包安装。原生模型接入及聊天思考设置不变。
4. 核对 84% 的会话事件和 DSH 取消入口，记录能证明和不能证明的范围。审查结果写入 docs/reviews。

六阶段：需求、设计、计划已按用户明确要求收拢；实施、审查、交付依次进行。保留本地修改，不在本轮追加远端发布。
