# 0.1.1：取消服务商名称限制

此前 0.1.0 同时检查服务商标识和模型标识，这一限制不符合需求，由本插件引入。旧版需求、设计及验收记录中的服务商绑定描述自本版起作废。

现在只检查模型标识 Qwen3.8-27B。服务商改名后，摘要关闭思考和 16384 输出上限均保持生效；普通聊天、其他模型及原模型接入保持不变。

原生策略配置要求服务商和模型同时精确匹配，因此本版直接在固定版本原生压缩组件的上限判断处增加模型标识分支。自动触发、保留历史、摘要提交及失败保护仍为原生实现，无额外模型接入。
