# DSH × Qwen3.8 上下文压缩插件

让 DSH 在使用 Qwen3.8-27B 时完成上下文压缩，继续使用原来的模型接入、标准模式和历史对话。

## 它改了什么

- 只有生成压缩摘要时，向 Qwen 服务发送关闭思考的参数。
- 只有目标模型的摘要输出上限调整到 16384。
- 自动触发、手动压缩、近期历史保留和摘要安全替换继续由 DSH 原生功能负责。
- 普通聊天不关闭思考；不新增模型接入，不更换服务地址，不保存另一份密钥。
- 摘要请求的连接等待时间与原服务商配置一致（未配置时为 10 分钟），并限制完整请求总时长；不会被连接默认的 5 分钟等待提前截断，也不会因持续返回零碎内容无限等待。
- 标准模式下，自动或手动压缩失败、取消、未完成后，停止后续聊天请求；重开对话仍然有效。使用 `/compact` 重试，成功后才恢复聊天，不会偷偷重试或带着失败状态继续回答。

这不是把思考过程在页面上隐藏，而是让服务在这次摘要请求中不生成思考过程。

## 当前适用范围

Windows、Node.js 24、DSH 0.1.2-rc.1 与 0.1.5-rc.1（插件本身不锁定 DSH 版本）、标准模式 standard、通过 OpenAI 兼容聊天接口提供的 Qwen3.8-27B。模型服务须支持 `chat_template_kwargs.enable_thinking=false`。

只匹配模型标识 `Qwen3.8-27B`，不检查服务商标识或显示名称。服务商随便改名，仍然生效；不需要设置额外环境变量，也不用创建另一个接入。

其他模型名称、自定义模式不在已验证范围内。插件运行时不检查 DSH 版本号；DSH 升级后若上游内部结构变化，需要在本仓库重新执行构建生成新安装包（结构不匹配时构建会明确报错拒绝生成，不会静默装出坏插件）。

## 安装

从本仓库 Releases 下载已发布的插件安装包和标注“安装插件”的脚本（附件文件名为 `install-plugin.ps1`）。本源码当前版本为 0.1.4，源码版本不代表 Releases 已同步。右键安装脚本，选择“使用 PowerShell 运行”，在弹出的文件选择窗口中选中安装包；不需要填写文件路径。

脚本会备份现有 web 配置，并调用 DSH 自带插件管理安装。如果你习惯命令行，等价操作是：

```powershell
dsh plugin --profile web add "下载的安装包路径" --trust-lockfile --ignore-scripts
```

等待正在执行的任务结束，重启 DSH。已安装列表中应出现 `dsh-qwen38-compaction`。重新打开原来的标准模式对话即可，不需要新建对话或重新选择模型。

包通过 DSH 的官方插件层加载，内含与固定版本匹配的原生通信组件和标准模式配置，不覆盖 DSH 安装目录中的文件。

如果你在应用配置中自定义过原 `llm-pi-ai` 的 config 或 `agent-presets` 的模式目录，不要直接套用默认安装：先保留这些设置，在插件对应入口中合并。通过页面保存的模型地址和凭据属于原 settings 设置，本插件直接沿用。

## 使用

照常聊天，达到 DSH 原生阈值时自动压缩；也可以使用原生 `/compact` 手动压缩。手动操作请在模型回复结束后进行。

判断成功看三件事：有完整摘要、上下文占用下降、继续对话能够使用之前的关键事实。仅“插件已安装”不是成功证据。

## 停用与恢复

在 web 配置的插件包列表停用本插件，然后重启 DSH，原生组件恢复工作。原模型设置和历史记录不需要搬迁。若界面只提供移除包操作，先使用其正常确认流程；无需手工删除目录。

如果此前曾直接修改 DSH 安装文件，请先备份，再只撤销那些旧修补；否则即使插件停用，旧修补仍会生效。本插件不会自动覆盖不认识的本机改动。

## 验证与边界

源码附带实际 HTTP 请求检查、原生循环自动压缩检查和手动压缩的失败保护检查。空摘要、输出截断、服务错误及取消不能用损坏摘要替换历史。

2026-09-09 真实服务验收通过：自动压缩从 102769 降至 26347 tokens，手动压缩从 24769 降至 777 tokens。关键事实只放在被压缩的最早历史中，压缩后继续提问，金额、日期、禁止事项、纠正后的联系人及待办全部正确。结果见 docs/reviews 下的验收记录；不公开真实对话、业务资料、服务地址或凭据。

摘要是有损整理，不可能保证每一句原文都留在模型当前上下文中。网络故障、模型服务不支持参数等问题会造成失败；插件不把失败结果冒充成功摘要。
